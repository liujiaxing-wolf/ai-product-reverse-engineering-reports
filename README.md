# AI 产品拆解报告集

四个 AI 创意产品的证据分级拆解，共 16 份静态 HTML 报告：

- OiiOii
- [Kling AI](https://kling.ai/app)
- [Vidu](https://www.vidu.cn/)
- [Google Flow](https://labs.google/fx/tools/flow)

每个产品包含四类报告：用户旅程、Agent 契约、功能等价 System Prompt、产品架构。

在线预览：<https://liujiaxing-wolf.github.io/ai-product-reverse-engineering-reports/>

## 说明

这些报告基于可观察页面、交互状态与公开资料进行分析。文中的“事实、推断、建议”按证据强度区分；架构和 Prompt 内容不代表相关产品的官方内部实现。

仓库仅保存静态 HTML 报告及导航页，不包含账号凭据、Cookie、访问令牌或生成素材。
