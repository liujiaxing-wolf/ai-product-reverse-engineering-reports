关键分支

正常路径

发现 → 输入/引用 → 配置 → 确认 → 生成 → 预览 → 入库。后半段若未实测，只按官方能力说明保留为未知。

修改/纠正

应从不满意结果回到提示词、引用或局部编辑，并使下游资产版本可追踪。当前是否支持依赖失效：未知。

失败/积分不足

计费门槛已确认，但 Web 端的预估、冻结、失败退款 UI 并未全部观察。不得将政策说明等同于已观察交互。

中断

页面关闭、任务取消、Agent 会话切换后的恢复与退款规则未实测，标记为未知。

跨表面不一致

  • 营销能力、表单参数与登录后任务状态属于不同证据层，不能互相替代。
  • 当前账号实际可用模型、工作台视觉布局、Agent 真实回复、错误恢复与中断传播；这些因无法登录而未观察。
  • Agent 文案声称“生成/完成”不构成资产完成证据；本报告要求预览、任务与资产三方一致。

优先级问题影响证据等级
P0生成前成本与确认不够统一用户可能在模型/时长/数量之间难以预估消耗已确认/未知并存

可比产品机会

  1. 在提交前给出模型、时长、数量、预计积分和失败退款规则的一体化确认卡。
  2. 用项目级依赖图连接创意、角色/主体、分镜、镜头、音频与成片，支持局部重算。
  3. 把 Agent 的计划、工具调用结果、任务状态和资产版本分栏展示，避免“对话已完成 ≠ 资产已完成”。
  4. 为登录前提供只读 Demo 项目，完整展示确认、处理中、失败、修改与导出路径。
