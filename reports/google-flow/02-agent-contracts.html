十节 I/O 合约卡

Google Flow Agent

  1. 核心目标：通过自然对话进行头脑风暴、故事板规划、提示词细化、媒体生成/编辑与项目资产整理。
  2. 触发条件：在 Flow 项目提示框开启 Agent；可展开侧栏，选择/创建项目级 Session。
  3. 输入信息：当前用户输入；长期用户信息未知；项目全局上下文（当前 Project、Agent Session、Agent Instructions、提示词、选中/拖入资产、角色与声音引用、模型/画幅/数量/时长、集合、Credits 与每日查询配额。）；上游 Agent 输出未知；官方模板/案例；工具与任务结果。
  4. 可观察判断：理解项目上下文与引用资产，选择模型，决定生成/编辑/批量/整理操作，并在消耗 Credits 前执行确认设置。
  5. 工具：使用功能命名，不冒充官方 API 名称；详见总工具表。
  6. 输出：Agent 对话、可执行提示词、图片/视频、编辑结果、重命名/集合/归档动作；媒体自动保存到当前项目。
  7. 全局上下文：读取项目、提示词、引用、参数、资产；写入任务/资产的真实行为仅在有官方或页面证据时确认。
  8. 完成条件：媒体已保存到当前项目，且生成/编辑结果与用户目标一致；资产操作应以项目状态为准。
  9. 异常与重试：失败、积分不足、中断、重复提交的实际 UI 处理若未观察，一律未知；建议幂等重试。
  10. 未确认问题：模型路由细节、失败退款、版本回滚、依赖失效与人工确认粒度。

五个最高价值验证问题

  1. Agent 何时自动继续，何时必须请求用户确认？
  2. 消耗额度前是否展示精确成本并支持取消？
  3. 任务失败或中断时，积分、状态和资产如何回滚？
  4. 修改角色/主体/参考后，哪些分镜与成片自动失效？
  5. Agent 声称完成时，是否同时验证任务成功、媒体可播放和资产已落库？
