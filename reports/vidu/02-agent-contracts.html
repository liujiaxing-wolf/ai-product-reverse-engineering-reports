十节 I/O 合约卡

Vidu Agent

  1. 核心目标：一句话生成 15–30 秒、多镜头、带配音的视频，面向电商与营销类成片。
  2. 触发条件：进入 /project，输入想法或任务，并配置时长、1080p、宽高比和旁白音色。
  3. 输入信息：当前用户输入；长期用户信息未知；项目全局上下文（项目创意、行业/商品、提示词、图片/主体引用、时长、分辨率、编码、画幅、生成模式、数量、旁白音色、任务状态、作品/主体库、积分资格。）；上游 Agent 输出未知；官方模板/案例；工具与任务结果。
  4. 可观察判断：判断商品/行业场景、成片时长、画幅、旁白与镜头组织；提交前校验输入完整性。
  5. 工具：使用功能命名，不冒充官方 API 名称；详见总工具表。
  6. 输出：项目、成片任务、案例复用入口；真实输出未生成，但页面明确成片目标。
  7. 全局上下文：读取项目、提示词、引用、参数、资产；写入任务/资产的真实行为仅在有官方或页面证据时确认。
  8. 完成条件：应以项目任务成功、视频资产可预览且音画完整为准；本次未触发。
  9. 异常与重试：失败、积分不足、中断、重复提交的实际 UI 处理若未观察，一律未知；建议幂等重试。
  10. 未确认问题：模型路由细节、失败退款、版本回滚、依赖失效与人工确认粒度。

证据：V-E03 V-E04 V-E12

Vidu Claw

  1. 核心目标：通过对话把一句创意转化为含分镜、脚本、配乐/配音的创意短片，并可调用 Vidu Skills。
  2. 触发条件：进入 /claw，选择极速或自动模式，输入消息/完整提示词，或从案例获得灵感。
  3. 输入信息：当前用户输入；长期用户信息未知；项目全局上下文（项目创意、行业/商品、提示词、图片/主体引用、时长、分辨率、编码、画幅、生成模式、数量、旁白音色、任务状态、作品/主体库、积分资格。）；上游 Agent 输出未知；官方模板/案例；工具与任务结果。
  4. 可观察判断：识别内容类型、是否需要规划、是否直接生成、采用哪些 Vidu Skills、积分消耗与结果核验。
  5. 工具：使用功能命名，不冒充官方 API 名称；详见总工具表。
  6. 输出：Agent 回复、创意方案、媒体任务、项目/资产；本次只观察入口和案例，不发送消息。
  7. 全局上下文：读取项目、提示词、引用、参数、资产；写入任务/资产的真实行为仅在有官方或页面证据时确认。
  8. 完成条件：以任务完成、视频资产落库、可预览且旁白/配乐/镜头符合要求为准。
  9. 异常与重试：失败、积分不足、中断、重复提交的实际 UI 处理若未观察，一律未知；建议幂等重试。
  10. 未确认问题：模型路由细节、失败退款、版本回滚、依赖失效与人工确认粒度。

证据：V-E05 V-E06 V-E07 V-E11

五个最高价值验证问题

  1. Agent 何时自动继续，何时必须请求用户确认？
  2. 消耗额度前是否展示精确成本并支持取消？
  3. 任务失败或中断时，积分、状态和资产如何回滚？
  4. 修改角色/主体/参考后，哪些分镜与成片自动失效？
  5. Agent 声称完成时，是否同时验证任务成功、媒体可播放和资产已落库？
